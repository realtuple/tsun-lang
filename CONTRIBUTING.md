# Contributing guidelines.

## What to do?
 - Implement new features
 - Fix bugs
 - Add and fix tests
 - Write documentation

## How to contribute?

### Pull requests
If you want to commit something to Tsun you should:
1. Fork this repository
2. Commit to your fork (new branch for new pull request is recommended)
3. Send pull request here
4. Wait for response

### Commit message style
Our commit style is [Conventional Commits](https://www.conventionalcommits.org/) style. Please use it. It will be verified by `commit-msg` hook.

### Rules and Recommendations
 - Please setup git local repository to use hooks from `.githooks` folder
 - Ensure your contribution is properly described.
 - Put only related changes. It will make reviewing easier and faster.
 - Search for similar pull requests before submitting. It may be that a similar pull request exist.
 - Keep your contribution small and focused on the topic.
